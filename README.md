# Front-end do Sidebrain

## 🚀 Tecnologias

- **React**: Biblioteca para construção de interfaces de usuário
- **Vite**: Ferramenta de build e servidor de desenvolvimento rápido
- **TypeScript**: Superset de JavaScript com tipagem estática
- **React Router**: Roteamento das páginas da aplicação
- **React Redux**: Gerenciamento de estado global
- **Axios**: Cliente HTTP para comunicação com a API
- **ESLint**: Ferramenta de linting para padronização e qualidade do código

## 🏗️ Arquitetura

Veja mais sobre nossa arquitetura [aqui](./docs/architecture.md)

## ⚙️ Rodando o projeto

1. Instale as dependências do projeto:
```bash
npm install
```

2. Crie o arquivo .env e preencha as variáveis:
```bash
cp .env.example .env
```

3. Rode a aplicação em ambiente dev usando:
```bash
npm run dev
```

A aplicação estará disponível em `http://localhost:5173`.
